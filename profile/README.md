# 🌐 About SahyogSync

SahyogSync is an AI-first operational ecosystem designed to modernize social impact coordination through intelligent automation, geospatial systems, and real-time workflows.

The platform bridges the gap between:
- NGOs
- Volunteers
- Donors
- Community Resources

by transforming unstructured communication into actionable missions.

# 🛠️ Technology Stack

| Layer | Technologies |
|-------|--------------|
| **Backend** | FastAPI, Python 3.13, SQLAlchemy |
| **Frontend** | React.js, TailwindCSS, Vite |
| **Database** | PostgreSQL, NeonDB, PostGIS |
| **AI Layer** | Gemini API, LangChain |
| **Infrastructure** | Docker, Render, Vercel |
