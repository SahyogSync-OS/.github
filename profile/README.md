## 📖 Overview
**SahyogSync** is an AI-first operational ecosystem designed to bridge the gap in social impact logistics. By transforming unstructured data into actionable missions, we reduce operational friction for NGOs and maximize real-world impact.

> "Moving from manual coordination to intelligent synchronization."

---

## 🚀 Key Modules

### 🤖 AI-Powered Parsing
Leveraging **Gemini 1.5 Flash** to process donor messages and extract critical metadata:
- **Intent Extraction:** Auto-identifying donation types.
- **Urgency Scoring:** Prioritizing life-critical resources.
- **Entity Recognition:** Seamlessly extracting location and resource quantity.

### 📍 Smart Dispatch System
- **Geo-Matching:** Connecting volunteers to missions based on proximity.
- **FCFS Allocation:** Real-time mission claiming with live coordination.
- **OTP Verification:** Ensuring transparent delivery and audit-ready reporting.

### 📊 Mission Control
A comprehensive dashboard for NGOs to monitor inventory, track volunteer performance, and manage large-scale campaigns.

## 🤝 Contributing
SahyogSync is an open-source initiative. We follow a strict **Fork-and-PR** workflow:

1.  **Find an Issue:** Look for `good-first-issue` labels in our repositories.
2.  **Fork & Branch:** Create a branch using `feature/your-feature-name`.
3.  **Submit PR:** Ensure your code follows our linting standards and includes documentation.

## 🏛️ Engineering Standards
- **Modular Design:** AI logic is decoupled from core API services.
- **Security First:** JWT-based Auth and environment-level secret management.
- **Transparency:** All operational logs are verifiable and audit-ready.
